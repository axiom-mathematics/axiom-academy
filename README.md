# Axiom Institute of Mathematics

Static practice pages for [Axiom Institute of Mathematics](https://axiom-mathematics.com/). Math that finally makes sense.

Open `index.html`, or a published set with `?set=precalc-conics`. Answer checking runs in the browser with the same SymPy rules as the full app: an exact form, or a decimal accurate to three places (rounded or truncated), unless that problem sets a different rule. Attempt records stay in `localStorage` until a student downloads them.

This folder is what gets copied to the root of [axiom-mathematics/axiom-institute](https://github.com/axiom-mathematics/axiom-institute) so GitHub Pages can serve it. See the repository README for the publish and import steps.
