# Axiom Academy

Static practice pages for [Axiom Institute of Mathematics](https://axiom-mathematics.com/).

Open `index.html`, or a published set with `?set=precalc-conics`. Answer checking runs in the browser. Attempt records stay in `localStorage` until a student downloads them.

This folder is what gets copied to the root of [axiom-academy](https://github.com/axiom-mathematics/axiom-academy) so GitHub Pages can serve it. See the repository README for the publish and import steps.
